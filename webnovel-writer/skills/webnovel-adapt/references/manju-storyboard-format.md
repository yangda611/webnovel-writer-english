# 漫剧（动态漫 / AI 漫剧）分镜脚本格式

> 适用：`/webnovel-adapt --mode manju`。漫剧的每个镜头最终会变成一张图或一段图生视频，所以分镜脚本要同时满足导演读、画师/AI 出图、配音字幕三方使用。`adapt_lint.py --mode manju` 按本文件校验。

## 一、单集体量（默认值，可在 `改编/ADAPT_PROFILE.json` 的 `lint.manju` 覆盖）

| 指标 | 默认 | 说明 |
|------|------|------|
| 总时长 | 60-120 秒 | 各镜时长相加 |
| 镜头数 | 18-40 镜 | 平均 3 秒一镜；高潮段可 1-2 秒快切 |
| 单镜时长 | 1-6 秒 | 静帧超过 6 秒观众会觉得画面卡住 |
| 画面描述 | ≥12 字 | 不够出图 |
| 景别 | 至少 4 种 | 漫剧靠景别变化制造运动感 |
| 运镜 | 建议至少 3 种 | 静帧推拉摇是漫剧"动起来"的主要手段 |
| 台词密度 | ≤5 字/秒 | 气泡和字幕要读得完 |
| 单条台词 | ≤30 字 | 一个气泡放不下更多 |

## 二、文件格式

文件路径：`改编/漫剧/第{NNN}集-{集标题}.md`

```markdown
# 第1集：废物的测试石

> 来源：第0004章-迦南学院的考验
> 时长目标：90秒
> 画风：国风热血少年漫，厚涂，高对比冷暖光
> 本集爽点：扮猪吃虎

## 角色与场景资产

- **萧炎**：16岁少年，黑色短碎发，剑眉，瘦削，黑色粗布劲装，左手食指戴古朴黑戒，眼神沉静
- **药老**：白发白须老者灵魂体，半透明淡蓝光晕，宽袖灰袍，只在戒指周围出现
- **韩越**：中年男人，鹰钩鼻，灰色短须，墨绿长袍佩学院徽章，双手背后
- **演武场**：青石广场，中央一人高黑色测试石，四周看台，晨光斜射

## 分镜

| 镜号 | 时长 | 景别 | 运镜 | 画面 | 台词/字幕 | 音效/音乐 |
|------|------|------|------|------|-----------|-----------|
| 1 | 2s | 大特写 | 急推 | 黑色测试石表面，一点淡光从石心缓缓浮起 | — | 低频嗡鸣 |
| 2 | 3s | 全景 | 慢拉 | 演武场上百考生围成一圈，萧炎站在测试石前，背影瘦削 | 华服少年：萧家的废物也敢来？ | 人群哄笑 |
| ... |

【本集完】

> 🎣 结尾钩子：身份危机 · 白发长老盯住萧炎的戒指，瞳孔骤缩，嘴唇无声开合
```

### 列规则

| 列 | 规则 |
|----|------|
| 镜号 | 从 1 连续编号 |
| 时长 | 数字 + s，1-6 秒 |
| 景别 | 大远景 / 远景 / 全景 / 中景 / 中近景 / 近景 / 特写 / 大特写 |
| 运镜 | 固定 / 推 / 拉 / 摇 / 移 / 跟 / 升 / 降 / 环绕 / 甩 / 变焦 / 俯拍 / 仰拍 / 主观；可组合，如"慢推+仰拍" |
| 画面 | 一句话写清：谁、在哪、什么动作、什么表情、光线或关键道具。只写一个瞬间，不写过程 |
| 台词/字幕 | `角色：台词`；OS 写 `角色（OS）：…`；旁白写 `旁白：…`；多人用 `；` 分隔；无台词写 `—` |
| 音效/音乐 | 可空，写具体声音而不是情绪词 |

## 三、画面描述写法

漫剧的画面列会直接喂给出图模型，所以写法和小说不同：

1. **一个镜头一个瞬间**。"萧炎走过去然后把手放上去"是两个镜头。
2. **写可见的东西**：表情、手势、光、道具、构图位置。不写"他很紧张"，写"他喉结滚动，指尖悬在石面上一寸"。
3. **角色外观以资产表为准**。画面里不要重新描述发型服装，只写本镜的变化（受伤、换装、表情）。
4. **构图写清前后景**："前景虚化的戒指，后景萧炎侧脸"能直接变成镜头。
5. **特效写具体**："斗气化成淡金色气流缠绕右拳"，不写"气势惊人"。

## 四、节奏模板（90 秒）

| 镜头段 | 秒数 | 任务 |
|--------|------|------|
| 1-3 镜 | 0-6s | 冲击镜头（大特写/急推/一句狠话）。禁止空镜开场 |
| 4-10 镜 | 6-35s | 建立处境与对手，反派加压 |
| 11-20 镜 | 35-70s | 冲突升级与反转，动作段用 1-2 秒快切 |
| 21-25 镜 | 70-85s | 爽点兑现，给慢推特写留情绪时间 |
| 末 1-3 镜 | 85-90s | 钩子镜头，停在悬念画面上 |

## 五、AI 漫剧一致性要求

- 每个说话角色都必须在资产表里登记，外观锚点 ≥15 字，包含年龄、发型、服装、标志物。
- 同一场景连续镜头保持光线方向一致；换时间必须在画面列写明。
- 标志性道具（戒指、武器、徽章）在资产表或首次出现的画面里写清外形。
- 避免画面里出现大段文字（招牌、信件），需要时改为字幕。

## 六、常见错误

| 错误 | 正确 |
|------|------|
| 画面："萧炎很生气" | 画面："萧炎下颌绷紧，眼底映出对手的拳头" |
| 画面："测试开始了" | 拆成"考官抬手"和"测试石亮起"两镜 |
| 一镜 3 秒配 25 字台词 | 拆镜，或把台词砍到 15 字以内 |
| 全集 30 镜全是中景固定 | 交替使用特写、全景、推拉和仰俯拍 |
| 资产表没有反派，但反派说话 | 补登记 |
| 一个大特写里同时要拍眼睛和手 | 取景框装不下，一格只拍一个身体部位 |
| 画面写"袖中的手""冰冷的表面""不受控地" | 看不见的就不写，换成可见的姿态和光 |
| 角色在画面里叫"对手""那人" | 一律用资产表里的名字，出图时才能自动匹配资产 |
| 同一种灵体或特效，前后颜色不一致 | 颜色、材质以资产表为准 |
| 两个角色共用同一个外观锚点（都是"长眉白发"） | 资产表里每个角色至少有一个独有的锚点，画面里不要把别人的锚点借给他 |
| 说话人不在画面里却没标注 | 台词写成 `角色（画外音）：…` |
| 拟声字写进画面（"啪"地合上） | 出图模型可能把字画进图，声音一律放音效列 |
| 否定描述（"没有一丝光""未湿"） | 写成正面终态："指缝暗下""碎发干爽" |
| 同一只手、同一件道具没写左右 | 写明"右手""左手食指上的戒指"，出图时道具才不会换手 |
| 前一镜拳头已打空，后一镜又停在胸前 | 相邻镜头的动作结果要接得上 |
