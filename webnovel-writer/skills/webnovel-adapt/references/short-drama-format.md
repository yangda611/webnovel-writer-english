# 竖屏短剧剧本格式与单集标准

> 适用：`/webnovel-adapt --mode short-drama`。本文件定义输出格式和可机械检查的硬指标；`adapt_lint.py --mode short-drama` 按本文件校验。叙事质量见 `adaptation-craft.md` 与 `adapt-reviewer` 评分表。

## 一、单集体量（默认值，可在 `改编/ADAPT_PROFILE.json` 的 `lint.short-drama` 覆盖）

| 指标 | 默认 | 说明 |
|------|------|------|
| 时长 | 90-150 秒 | 估算：对白字数 ÷ 4.5 字/秒 + 动作行数 × 2.5 秒 |
| 场次 | 2-5 场 | 1 分钟以内换景超过 3 次，观众会丢失空间感 |
| 有效对白 | 18-32 句 | 少于 18 句撑不满 90 秒；多于 32 句变成说书 |
| 单句台词 | ≤30 字（>45 字为错误） | 竖屏字幕一屏约 15 字，单句最多两屏 |
| OS/旁白占比 | ≤30% | 内心戏优先外化成动作、道具、对手戏 |
| 景别 | 至少 3 种 | 全景/中景/近景/特写，不能全程中景 |

## 二、文件格式

文件路径：`改编/短剧/第{NNN}集-{集标题}.md`

```markdown
# 第3集：测试石亮了

> 来源：第0004章-迦南学院的考验（前半）
> 时长目标：120秒
> 本集爽点：扮猪吃虎 · 测试结果反转
> 前情：纳兰家信使出现在学院门口

## 场1 内 学院客房 晨

**人物**：萧炎、药老（戒指内，只闻其声）

△（特写）黑色古戒。戒面上一缕白烟一闪而灭。
**药老**（画外音，懒洋洋）：小子，纳兰家的人就在门口，你手抖什么？
**萧炎**（攥紧戒指）：不是抖。是等不及了。

## 场2 外 演武场 日

**人物**：萧炎、韩越、华服少年、考生若干

△（全景）上百考生围着一块一人高的黑色测试石。
**华服少年**（拦路，冷笑）：萧家那个废物？测试石碰一下都嫌脏。
...

【本集完】

> 🎣 结尾钩子：身份危机 · 白发长老盯着萧炎的戒指，低声：这股气息……不可能……
```

### 行类型（只允许以下几种）

| 行 | 写法 | 规则 |
|----|------|------|
| 集标题 | `# 第N集：标题` | 首行；标题 4-10 字，写看点不写概括 |
| 元信息 | `> 来源：/ 时长目标：/ 本集爽点：/ 前情：` | `来源` 必填，标到章节，便于回溯原著 |
| 场头 | `## 场N 内/外 地点 日/夜/晨/昏` | 必含内外与时间 |
| 人物行 | `**人物**：A、B` | 每场一行，首次出场可附一句外观 |
| 动作行 | `△（景别/运镜）可拍到的画面` | 只写镜头能拍到的东西 |
| 对白行 | `**角色**（表演提示）：台词` | 台词不加引号；OS 写 `（OS）`，画外音写 `（画外音）` |
| 音乐/音效 | `♪ 低频鼓点渐入` | 可选，一集不超过 4 处 |
| 字幕/卡 | `【字幕：三年后】`、`【闪回】`、`【闪回结束】` | 只在必要时用 |
| 结束 | `【本集完】` + `> 🎣 结尾钩子：类型 · 具体内容` | 必填 |

**禁止裸叙述**：剧本里不能出现小说式的叙述段落。所有信息必须落在动作行、对白行或字幕卡上。

## 三、单集结构（120 秒版）

| 时间 | 段落 | 任务 |
|------|------|------|
| 0-3 秒 | 黄金3秒 | 第一个镜头就要有冲突、异常画面或一句狠话。禁止空镜、起床、天气 |
| 3-15 秒 | 接钩 | 非首集：5 秒内回应上集钩子，但只给半个答案 |
| 15-90 秒 | 升级 | 至少 2 次压力升级（反派加码 / 规则加码 / 误会加深），每场之间要递进 |
| 90-110 秒 | 兑现 | 本集主爽点或情绪点必须落地，给观众"值了"的回报 |
| 110-120 秒 | 卡点 | 抛出新问题后硬切；切在答案揭晓的前一刻 |

## 四、结尾钩子类型

| 类型 | 切点 | 示例 |
|------|------|------|
| 身份危机 | 秘密将要暴露 | 长老盯住戒指："这股气息……不可能……" |
| 生死悬念 | 致命一击落下前 | 刀尖停在喉咙前一寸 |
| 反转揭露 | 真相说出一半 | "下毒的人不是她，是——" |
| 情绪断点 | 告白/对决的前一秒 | 手机亮起：前女友来电 |
| 信息炸弹 | 新信息改写局势 | 信使递来的信封上，盖着纳兰家的火漆 |
| 选择困境 | 主角必须二选一 | 救师父还是保住名额 |

同一个钩子只能卡一次。下一集开头必须兑现或部分兑现，不能 10 秒内化解成"虚惊一场"。

## 五、付费卡点（分集规划时标注）

- 首个卡点：第 8-12 集，用全剧前段最强的悬念。
- 之后每 8-12 集一个卡点，卡点之间至少隔 5 集。
- 卡点集的结尾钩子强度必须是 strong；卡点后的第一集必须先兑现。
- 改编篇幅不足 8 集时不设付费卡点，只保证集集有钩。

## 六、常见格式错误

| 错误 | 正确 |
|------|------|
| `△ 萧炎心中暗道，绝不能失败。` | `**萧炎**（OS）：绝不能输。` 或 `△（特写）萧炎指节攥得发白。` |
| `△ 他感到欣慰，同时又有些担忧。` | `△（近景）萧炎嘴角刚扬起，又在看到长老的眼神时压平。` |
| 一句台词交代三条背景信息 | 拆成对手戏，用质问-回答带出信息 |
| 结尾总结"今天的考验结束了" | 结尾停在新威胁上 |
| 全场都是 `△（中景）` | 用特写给道具和表情，用全景给群体反应 |
