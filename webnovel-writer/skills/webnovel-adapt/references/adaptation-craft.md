# 小说 → 短剧 / 漫剧 改编方法

> 格式见 `short-drama-format.md` 与 `manju-storyboard-format.md`。本文件讲怎么改：取舍、外化、压缩、加强冲突。

## 一、改编三原则

1. **忠于原著事实，不忠于原著叙述**。人物关系、设定、因果、伏笔不能改；叙述顺序、场景切分、台词措辞、信息揭露时机可以改。
2. **看得见才算数**。小说靠"他感到"传递情绪，剧本只能靠画面、动作、台词、声音。原著里每一句心理描写都要找到可拍的替代。
3. **每集是独立商品**。观众可能从任何一集刷进来，每集都要有自己的冲突、兑现和钩子。

## 二、拆集（章 → 集）

| 原著章长 | 默认拆法 |
|----------|----------|
| ≤1500 字 | 1 章 = 1 集，或两章合一集 |
| 1500-3000 字 | 1 章 = 1-2 集 |
| >3000 字 | 按冲突节点拆，每个"压力→兑现"循环一集 |

拆集规则：

- 每集必须切在一个**未回答的问题**上。原著章节如果在平静处结束，就把下一章的冲突开头提前到本集结尾。
- 原著里的"过渡段"（赶路、休息、回忆）压缩成 1-2 个镜头，或并入相邻冲突场。
- 一集只服务一个主爽点，多余的爽点挪到下一集，形成"集集有爽"。

## 三、外化技巧（内心 → 可拍）

| 原著写法 | 改编手段 | 示例 |
|----------|----------|------|
| 心理活动 | 动作细节 | "他很紧张" → 指节攥得发白、喉结滚动 |
| 判断/推理 | 对手戏问答 | 让配角问"你怎么知道？"，主角答出推理 |
| 回忆 | 1-3 镜闪回 + 字幕卡 | 【闪回】三年前退婚现场的一巴掌 |
| 实力对比 | 数值/道具可视化 | 测试石光芒颜色、裂纹 |
| 旁人震惊 | 反应镜头 | 三连特写：考官挑眉、长老瞳孔收缩、反派笑容僵住 |
| 无法外化的关键内心 | OS，限一句 | **萧炎**（OS）：三年之约，还剩两年。 |

OS 是最后手段，占比不超过对白的 30%。

## 四、强化冲突（短剧化）

原著网文的冲突在短剧里通常偏弱，需要在**不改事实**的前提下加压：

1. **反派台词加狠**：原著"又一个废物"→"萧家的废物？测试石碰一下都嫌脏。"台词更具体、更侮辱，但不改变人物立场。
2. **给冲突加观众**：私下冲突改到众人面前，打脸效果放大。前提是原著没有限定"无人在场"。
3. **给压力加倒计时**：原著有时间限制的，把时间限制说出来。
4. **兑现前先压到最低**：主角翻盘前，让观众看到"他真的要输了"的那一秒。
5. **反应镜头不能省**：爽点的一半来自围观者的反应。

**不能做的事**：新增原著没有的角色关系、改变战斗结果、让角色知道他不该知道的信息、提前揭露原著后文才揭露的秘密。需要新增时，写进 `改编/改编说明.md` 的"改编改动"段，供作者确认。

## 五、台词改写

- 小说对白往往偏长、偏书面。改成短句、口语、带情绪。
- 每句台词只做一件事：施压、反击、透露信息、制造悬念，四选一。
- 主角台词要短，越强越短；反派台词可以长一点，因为他在"嚣张"。
- 删掉"嗯""好的""是吗"这种不推进的台词。
- 角色口头禅和称谓沿用原著设定，不擅自改。

## 六、改编说明文件

每次改编都维护 `改编/改编说明.md`：

```markdown
# 改编说明

## 改编配置
- 模式：short-drama / manju
- 原著范围：第1-10章
- 集数：12集
- 单集时长目标：120秒

## 分集对照
| 集 | 原著来源 | 主爽点 | 结尾钩子 | 卡点 |
|----|----------|--------|----------|------|
| 1 | 第1章 | 退婚受辱 | 戒指里有人说话 | |

## 改编改动（需作者确认）
- 第3集：把原著中私下的挑衅改到演武场众人面前（原著未限定场合）

## 删减
- 第2章赶路段压缩为 1 镜
```

## 七、高频失分（来自样稿审查，起草前必读）

| 失分 | 为什么扣分 | 改法 |
|------|------------|------|
| 首镜是睁眼/起床/晨光 | 黄金3秒没有冲突，观众直接划走 | 第一镜给冲突物件（信、戒指异动）或一句狠话；起床戏压成一镜或删掉 |
| 主角的核心约束没被考验 | 原著里"只露三成""不能暴露"这类约束，是本集真正的冲突。只说一次、不考验，戏就是平的 | 安排一拍"约束差点失守"：被逼到边缘、力量差点失控、导师喝止、主角硬压回去 |
| 对手/难度没变高 | 兑现前没压到低点，赢了也不爽 | 原著对手不能换，就让约束把主角的有效实力压低；难度来自规则和约束，不能凭空改对手 |
| 打脸线没回收 | 开场羞辱主角的人在兑现时没有反应镜头 | 兑现后补一个羞辱者的特写反应；主角的一句台词可以回指那句羞辱 |
| 钩子前有松气台词 | "第一步，成了"一类收束台词会泄掉悬念 | 删掉，或者让松气被打断 |
| 钩子只落在旁人身上 | 主角不知情，危机没有逼近 | 最后一镜回到主角，给他一个察觉异样的动作，但不替原著回答问题 |
| 秘密的暴露范围被放大 | 原著"若有若无的气息"被改成全场可见的异象 | 异常只让主角和观众感知：特写一闪而灭，主角下意识藏手 |
| 新增对手戏没登记 | 原著没有的冲突（考官顶撞长老）改变了人物关系 | 尽量弱化成单方面动作；保留的话写进 `改编说明.md` 的"改编改动" |
| 台词把利害说过头 | "你我都得死"超出原著给出的后果 | 后果以原著和大纲为准，可以说得狠，但不能说错 |
| 说明性台词 | "韩越亲自盯着"是在给观众念设定 | 身份、规则交给字幕卡、表情或对手戏 |
| 一句台词塞多条信息 | 规则加威胁挤在一句里，观众记不住 | 一句只做一件事，拆开或用停顿隔开 |
| 两处台词重复同一个关键词 | 中段先用了"不可能"，结尾那句的分量就被削弱 | 关键台词全集只出现一次 |
| 首集画外音没有画面锚点 | 观众不知道是谁在说话 | 导师第一次发声时给戒指或虚影一个特写 |

| 主角的应对方式被改 | 原著"静静走过、不屑争执"被改成撞人、拨开对方，人物性格就变了 | 加压只加在对手身上；主角的回应方式以原著为准 |
| 全场可见的异象 | "光芒冲到最亮""戒指冒白气"会让旁人也看见秘密，和"隐藏实力"矛盾 | 主角压实力，就写"光芒刚涌起就被压回薄光"；导师的存在不在外界留下可见痕迹 |
| 信息顺序调整没登记 | 原著的提醒在 A 之后，改编挪到 A 之前，因果就变了 | 能不挪就不挪；挪了就登记 |
| 新增背景事实 | "三年没涨过斗气"这类原著没有的数字或经历 | 只用原著和设定里有的事实；需要强调时用笼统说法（"出了名的废物"） |
| 胜负没落到画面上 | 扣住手腕之后直接抱拳，"制敌"没有结果 | 补一个看得见的结果：跪地、斗气散掉、裁判表情 |
| 动作没有因果 | 对手出拳，下一镜主角就踉跄后退，中间没有格挡或命中 | 每次位置变化前，给一镜原因 |
| 几个反派共用一个骂法 | 三个人都骂"废物"，没有区分度 | 每个施压者用自己的方式压人：出身、实力、规则 |
| 首集用观众不认识的名词开场 | 第一集观众不知道"纳兰"是谁，这个名字没有冲突感 | 首集冷开场用看得见的羞辱或危机，专有名词往后放 |

| 原著对手比主角弱，"难度提高"不成立 | 观众感觉不到危险 | 不换对手，改为加规则代价（"出擂即淘汰"）并先拍一次代价兑现（别人被打下台） |
| 隐藏实力的爽感看不见 | 观众不知道他"其实更强" | 胜负后给一格余力画面：气息平稳、衣角未乱、不见汗 |
| 反转没有落差 | 观众不知道主角之前的处境 | 反转前让路人说一句前情（"听说他斗之气都散光了"），只用原著已有的事实 |
| 认可在发现之前就给了 | "过"说在长老察觉之前，危机感被提前卸掉 | 先发现异常，再给结果，让结果带上悬念 |
| 观察者与秘密之间没有画面连接 | 长老看的是背影，却"感应到戒指" | 加一个观察者主观镜头，让视线落在秘密物件上 |
| 首集用设定黑话 | "吸力""三年之约"对新观众是空信息 | 首集用观众能直接理解的利害（"输了你就永远是废物"），设定名词往后放 |
| 采纳审查意见时加了原著没有的剧情 | 审查建议"散场后让他来见我"，原著并没有召见 | 审查意见也要过一遍忠实度检查，新增剧情不采纳 |
| 预读后续章节时把后文细节带进本集 | 本集对应第1章，结尾却写进第2章才出现的"车下检修门红锁"，被判未登记新增事实 | 严守本集原著章节边界；若为做结尾钩子必须提前半拍，必须在 `改编说明.md` 登记 |
| 主角私密系统/面板写成旁人可见的外显特效 | 原著"只有她能看见的细字"写成"手腕浮现光字、旁人看向她手腕"，违反设定可见性 | 面板/印记一律标明"（主观视角：仅主角可见）"，旁人只能看见主角掀袖、按手腕的动作 |

漫剧额外的高频失分：

| 失分 | 改法 |
|------|------|
| 一格写了"攥紧，又松开""蹙眉，随即冷脸" | 一格只留一个定格瞬间，过程拆成多镜 |
| 画面列写"镜头从高空降下" | 运镜只写在运镜列 |
| 画面要求画出"四个金色大字" | 出图模型画不准汉字，文字一律走字幕 |
| 画面里出现资产表没有的场景和道具（卧房、擂台、折扇） | 资产表要覆盖本集所有场景、标志道具；先补资产再写分镜 |
| 角色出现方式违反资产表（"只在戒指周围"却浮在肩后） | 画面服从资产表，需要变化就先改资产表 |
| 画面写"鸦雀无声""目光如鹰" | 改成可画的东西：张着嘴的群像、眯起的眼 |
| 资产表把中段才发生的状态写成初始常驻（如第13镜才包扎的"右手缠白纱布"） | 资产表写初始常驻外观，阶段性变化标明"（第N镜起……）" |

## 八、改编自检清单

1. 有没有改变原著事实（结果、关系、设定、知识边界）？
2. 每集前 3 秒有没有冲击？
3. 每集有没有一个落地的爽点或情绪点？
4. 每集结尾有没有一个新的未回答问题？
5. 原著的心理描写是否都外化了？OS 有没有超量？
6. 上一集的钩子在本集有没有兑现？
7. 有没有原著根本不存在的场面（打斗结果、秘密揭露）被擅自加进来？
