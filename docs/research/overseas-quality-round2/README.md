## 自动化链路

`webnovel-writer/scripts/data_modules/tests/test_reviewed_sample_chain.py` 将四组审读正文送入临时项目，验证 profile、合同刷新、上下文、写前门、按 reviewer JSON 提交、state/index/Dashboard/状态报告计量、重复投影及重复初始化。Windows 定向结果：`4 passed`。计量分别使用英文 `words` 和中文 `characters`，且逐章、数据库、状态和面板总量一致。

该集成测试复用现有 reviewer JSON，并将大纲命中与事实抽取输入设为空；它验证审阅门控后的提交和投影，不验证语义事实抽取、真实大纲履约，也不证明系统能够自行创作或审查合格小说。

## 证据边界

样章由助手原创，审读由不同模型会话完成；未进行英语母语编辑、真人盲评、目标读者测试、平台或出版方核实。审读零阻断只表示当前两章范围内没有发现可验证的五维事实矛盾。具体非阻断建议和已修订问题均保留在逐篇报告中，没有据此将 draft 题材包升级为正式支持。
