# 第0001章-不记得的路

记忆师说得很清楚：过河只收一段路。

诺娅本来选好了。七岁那年，她在一条泥路上走失，天黑后才被人找到。忘了那里，损失不大。她把指尖放进银碗，水面却映出了昨夜的窄巷，埃文站在伞下替她挡风。

“它收你最常回想的那段。”记忆师说。

对岸的钟楼敲了半下，被炮声截断。信还在诺娅的内袋，封蜡抵着肋骨。她把手往碗里浸了一点，巷口的灯随之暗下去。

埃文拉住了她的袖口。

“换我的。”

“你连自己会失去哪段都不知道。”

“你也不知道。”

诺娅没有抽回手，也没让记忆师继续。昨晚在巷口，是她先吻了他；今早醒来，她却假装一切都可以等送完信再谈。现在连拖延都要被算作选择。

“如果我忘了，”她问，“你会不会告诉我，我们早就说好了什么？”

埃文松开袖口。他从身后的台阶上退下一阶，像是要让她看清自己没有挡住渡船。

“我会问你，愿不愿意重新认识我。”

银碗里的灯还亮着。诺娅从水中抬起一根手指，记忆师皱了皱眉，却没有催。

“等我过了河再问。”她说。

她把整只手沉了下去。渡船靠岸时，她记得这封信要送给谁，也记得身后有个人正在等一个答案。她只是不记得，那条巷子里曾经下过雨。
